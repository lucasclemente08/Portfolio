## 📝 Description

Personal web portfolio built with **React** and **Framer Motion**. It showcases my profile as a frontend developer, my projects, technical experience, services, and contact information. The design is fully **responsive** with smooth animations.

**Live demo:** [lucasclemente08.github.io/Portfolio](https://lucasclemente08.github.io/Portfolio)

---

## ✨ Features

- 🎨 **Responsive design** — adapts to desktop, tablet, and mobile
- 🎬 **Framer Motion animations** — entrance and scroll animations
- 🧭 **Floating navigation** — bottom nav bar with active section indicator
- 📂 **Projects section** — cards with GitHub links and live demos
- 🛠️ **Experience section** — frontend and backend skills
- 💼 **Services section** — Fiverr and Chrome extensions
- ⭐ **Testimonials section** — client reviews
- 📬 **Contact section** — links to LinkedIn and GitHub
- 🔍 **SEO optimized** — meta tags, Open Graph
- 🌐 **Multilingual** — README in Spanish and English

## 🚀 Installation

1. **Clone the repository:**

```bash
git clone https://github.com/lucasclemente08/Portfolio.git
cd Portfolio
```

2. **Install dependencies:**

```bash
npm install
```

3. **Start the development server:**

```bash
npm start
```

The app opens at `http://localhost:3000`.

---

## 📜 Available Scripts

| Script | Description |
|---|---|
| `npm start` | Starts the development server |
| `npm run build` | Builds for production into `build/` |
| `npm test` | Runs the test suite |
| `npm run deploy` | Deploys to GitHub Pages |

## 🌍 Deployment

The site is deployed on **GitHub Pages**:

```bash
npm run deploy
```

This builds the project (`npm run build`) and publishes the `build/` folder to the `gh-pages` branch.
