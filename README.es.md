## 📝 Descripción

Portfolio web personal construido con **React** y **Framer Motion**. Presenta información sobre mi perfil como desarrollador frontend, mis proyectos, experiencia técnica, servicios y formas de contacto. El diseño es completamente **responsive** con animaciones suaves.

**Demo en vivo:** [lucasclemente08.github.io/Portfolio](https://lucasclemente08.github.io/Portfolio)

---

## ✨ Características

- 🎨 **Diseño responsive** — adapta a desktop, tablet y móvil
- 🎬 **Animaciones con Framer Motion** — entrada y scroll animations
- 🧭 **Navegación flotante** — barra de nav inferior con indicador de sección activa
- 📂 **Sección de proyectos** — tarjetas con links a GitHub y demos
- 🛠️ **Sección de experiencia** — habilidades frontend y backend
- 💼 **Sección de servicios** — Fiverr y extensiones de Chrome
- ⭐ **Sección de testimonios** — reseñas de clientes
- 📬 **Sección de contacto** — links a LinkedIn y GitHub
- 🔍 **SEO optimizado** — meta tags, Open Graph
- 🌐 **Multi-idioma** — README en español e inglés

## 🚀 Instalación

1. **Clonar el repositorio:**

```bash
git clone https://github.com/lucasclemente08/Portfolio.git
cd Portfolio
```

2. **Instalar dependencias:**

```bash
npm install
```

3. **Iniciar en modo desarrollo:**

```bash
npm start
```

La app se abre en `http://localhost:3000`.

---

## 📜 Scripts Disponibles

| Script | Descripción |
|---|---|
| `npm start` | Inicia el servidor de desarrollo |
| `npm run build` | Compila para producción en `build/` |
| `npm test` | Ejecuta los tests |
| `npm run deploy` | Deploy a GitHub Pages |

## 🌍 Deploy

El sitio está deployado en **GitHub Pages**:

```bash
npm run deploy
```

Esto compila el proyecto (`npm run build`) y publica la carpeta `build/` en la rama `gh-pages`.
